Borrador local

Lo que hagas acá no cambia la web publicada. El borrador queda solo en este navegador. Para publicar: exportá los dos archivos, reemplazá data/catalogo.json y data/negocio.json, ejecutá npm run build y subí los cambios con Git (ver README).
