Ingresar

Para publicar cambios, el panel usa un token de GitHub con permiso sobre el repositorio de la web. GitHub verifica el acceso: sin un token válido no se puede modificar nada.

Empieza con github_pat_. Se guarda solo en este navegador.

¿Cómo consigo el token?
  1. Con la cuenta dueña del repositorio Misiomis/burguer_truck, abrí GitHub › Fine-grained tokens › Generate new token.
  2. Nombre: “Panel El Buen Sabor”. Vencimiento: el que prefieras (por ejemplo, 1 año).
  3. Repository access: Only select repositories › burguer_truck.
  4. Permissions › Repository permissions › Contents: Read and write. Nada más.
  5. Generá el token, copialo y pegalo acá. Si lo perdés o alguien lo ve, borralo en GitHub y creá otro.

Los cambios se publican para todos recién cuando tocás “Revisar y publicar” y confirmás. La web se actualiza en 1 o 2 minutos.

Precio vacío = “a confirmar” (no se puede pedir). Para que un producto no se pueda pedir por hoy, marcalo “Agotado”.
